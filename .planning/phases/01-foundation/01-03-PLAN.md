<task type="auto">
  <name>Task 2: Fix portrait layout — form no longer cut off at bottom</name>
  <files>
    PandaAutomator/App/ContentView.swift
  </files>
  <action>
    The root cause: inside a ZStack, the VStack only sizes to its content height rather than filling the available space. The Form never gets told to expand, so it shrinks to content size and the bottom sections fall off screen in portrait.

    Fix: add `.frame(maxWidth: .infinity, maxHeight: .infinity)` to the VStack so it fills the ZStack, giving the Form the full available height to scroll within.

    Current VStack:
    ```swift
    VStack(spacing: 0) {
        Form { ... }
            .formStyle(.grouped)
            .scrollContentBackground(.hidden)

        if viewModel.showLogs { ... }
    }
    ```

    Updated VStack:
    ```swift
    VStack(spacing: 0) {
        Form { ... }
            .formStyle(.grouped)
            .scrollContentBackground(.hidden)

        if viewModel.showLogs { ... }
    }
    .frame(maxWidth: .infinity, maxHeight: .infinity)
    ```

    Do NOT set a fixed height on the Form itself — the Form is a ScrollView and should determine its own scroll region from available space.
  </action>
  <verify>
    -- Verify the file compiles: check the VStack now has the frame modifier
    grep -A2 "VStack(spacing: 0)" PandaAutomator/App/ContentView.swift
  </verify>
  <done>
    VStack has `.frame(maxWidth: .infinity, maxHeight: .infinity)`. Form fills portrait screen and all sections are reachable by scrolling.
  </done>
</task>

<task type="auto">
  <name>Task 3: Add dynamic input border color states</name>
  <files>
    PandaAutomator/Views/InputFormView.swift
  </files>
  <action>
    Replace the static `Color.green.opacity(0.6)` border color on both TextFields with computed border colors that reflect validation state.

    Add two private computed properties to InputFormView:

    ```swift
    private var surveyCodeBorderColor: Color {
        if viewModel.isRunning { return Color(.systemGray4) }
        if viewModel.surveyCode.isEmpty { return Color.green.opacity(0.6) }
        let clean = viewModel.surveyCode.replacingOccurrences(of: "-", with: "")
        return clean.count == 24 ? Color.green.opacity(0.6) : .red.opacity(0.7)
    }

    private var emailBorderColor: Color {
        if viewModel.isRunning { return Color(.systemGray4) }
        if viewModel.email.isEmpty { return Color.green.opacity(0.6) }
        let valid = viewModel.email.contains("@") && viewModel.email.contains(".")
        return valid ? Color.green.opacity(0.6) : .red.opacity(0.7)
    }
    ```

    Then update each TextField's `.overlay` to use the computed color:

    Survey Code TextField overlay:
    ```swift
    .overlay(
        RoundedRectangle(cornerRadius: 6)
            .stroke(surveyCodeBorderColor, lineWidth: 1.5)
    )
    ```

    Email TextField overlay:
    ```swift
    .overlay(
        RoundedRectangle(cornerRadius: 6)
            .stroke(emailBorderColor, lineWidth: 1.5)
    )
    ```

    Border state summary:
    - Empty field → green (0.6 opacity) — neutral, inviting
    - Has content, valid → green (0.6 opacity) — good
    - Has content, invalid → red (0.7 opacity) — feedback
    - Running → systemGray4 — disabled visual
  </action>
  <verify>
    grep -n "surveyCodeBorderColor\|emailBorderColor" PandaAutomator/Views/InputFormView.swift
  </verify>
  <done>
    InputFormView has both computed border color properties. Both TextField overlays use the computed colors. Border reacts to isRunning, empty, valid, and invalid states.
  </done>
