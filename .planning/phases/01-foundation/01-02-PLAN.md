       - `@StateObject private var viewModel = AutomationViewModel()`
       - `NavigationStack` (or `NavigationView` for iOS 16 compat) with title "Panda"
       - `ZStack` containing:
         a. Panda watermark: `Image("pandaEating").resizable().scaledToFill().opacity(0.06).ignoresSafeArea().allowsHitTesting(false)`
         b. `VStack(spacing: 0)` containing:
            - `Form` with `.formStyle(.grouped)` containing `InputFormView(viewModel: viewModel)`
            - Frame constraint: when `showLogs` is true, form takes top ~50% of screen
            - Conditional log area: `if viewModel.showLogs` shows a `ScrollViewReader` with `ScrollView` containing `LazyVStack` of log messages in monospaced caption font
            - Log area auto-scrolls to bottom on new messages via `.onChange(of: viewModel.logMessages.count)`
            - Log area background: `Color(.systemBackground)` to sit cleanly below the form
       - `.tint(.green)` on the outer container for green accent on all interactive elements
       - `.onAppear { viewModel.setupEngine() }` -- critical: engine must attach to window here, not in init

    3. **Create `InputFormView.swift`** -- extracted form content:
       - `@ObservedObject var viewModel: AutomationViewModel`
       - `Section("Survey Code")`:
         - `TextField("1234-5678-9012-3456-7890-1234", text: $viewModel.surveyCode)`
         - `.keyboardType(.default)` (codes may contain letters)
         - `.autocorrectionDisabled()` and `.textInputAutocapitalization(.characters)` for uppercase
         - `.onChange(of: viewModel.surveyCode)` calls `viewModel.surveyCode = viewModel.formatCodeWithDashes(viewModel.surveyCode)`
         - `.disabled(viewModel.isRunning)` (FORM-04)
       - `Section("Email")`:
         - `TextField("you@example.com", text: $viewModel.email)`
         - `.keyboardType(.emailAddress)`
         - `.autocorrectionDisabled()` and `.textInputAutocapitalization(.never)`
         - `.disabled(viewModel.isRunning)` (FORM-04)
       - `Section` (no header) containing:
         - `Button("Run") { viewModel.startAutomation() }` with `.buttonStyle(.borderedProminent)` and `.tint(.green)` and `.frame(maxWidth: .infinity)` -- filled green with white text
         - `.disabled(!viewModel.isValid || viewModel.isRunning)` (FORM-03, FORM-04)
         - If `viewModel.isRunning`, show a `ProgressView()` inline or replace button text with "Running..."
         - `Toggle("Show Logs", isOn: $viewModel.showLogs)` -- standard iOS toggle style

    4. **Update Xcode project** to include the new files and asset catalog in the build target. Make sure the Assets.xcassets folder in `Resources/` is referenced by the project.
