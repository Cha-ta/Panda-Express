       - Class conforming to `NSObject, WKScriptMessageHandler`

       - Holds a closure `var onLog: ((String) -> Void)?` to forward messages to ViewModel

    3. Create `PandaAutomator/Engine/AutomationEngine.swift`:
       - `@MainActor class AutomationEngine: NSObject, WKNavigationDelegate`
       - Private `WKWebView!` property
       - Private `JSBridgeHandler` property
       - `func setup()` method that:
         a. Creates `WKWebViewConfiguration` with `WKUserContentController`
         b. Adds anti-detection `WKUserScript` at `.atDocumentStart`:
            `Object.defineProperty(navigator, 'webdriver', { get: () => undefined });`
            `Object.defineProperty(navigator, 'plugins', { get: () => [1, 2, 3] });`
         c. Registers JSBridgeHandler on "log" message name
         d. Creates `WKWebView(frame: .zero, configuration: config)`
         e. Sets `webView.navigationDelegate = self`
         f. Sets `webView.customUserAgent` to clean Mobile Safari string:
            `"Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1"`
         g. Attaches to `UIWindowScene` window: `scene?.windows.first?.addSubview(webView)` using `connectedScenes` API (NOT deprecated `UIApplication.shared.windows`)
       - `func loadFeedbackPage()` that loads `https://www.pandaexpress.com/feedback`
       - `var onLog: ((String) -> Void)?` property wired through to JSBridgeHandler
       - Stub `func run(code: String, email: String)` that calls `loadFeedbackPage()` (Phase 2 fills in the real logic)
       - `webView(_:didFinish:)` delegate method that calls `onLog?("Page loaded")`

    4. Update `PandaAutomatorApp.swift` to use SwiftUI App lifecycle with a simple placeholder ContentView (just Text("Panda") for now — Plan 02 builds the real UI).

    IMPORTANT: Use `ObservableObject` with `@Published` (NOT `@Observable`) because deployment target is iOS 16.0. `@Observable` requires iOS 17+.

    IMPORTANT: Call `engine.setup()` from the view's `onAppear`, NOT from `init()`, because `UIWindowScene` may not be connected yet at init time.
